# 🧠 Stroke Prediction Web App

A machine learning-powered web application built with **Flask** that predicts the likelihood of a person experiencing a stroke. Users provide health-related data such as age, BMI, glucose levels, and lifestyle habits. The app uses a trained model to evaluate the risk and provide a prediction result instantly.

---

## 🛠️ Technologies Used

- 🔮 **Python** – Backend logic & ML processing
- ⚗️ **Flask** – Lightweight web framework
- 🤖 **Scikit-learn** – Machine learning model training
- 📊 **Pandas & NumPy** – Data preprocessing and handling
- 💾 **Joblib** – Model serialization and loading
- 🎨 **Bootstrap 5** – Responsive frontend styling
- 🌐 **HTML/CSS/JavaScript** – User interface

---

## ✨ Features

- 🔍 Predicts stroke likelihood from personal health data
- 📝 Collects user input through a friendly, styled form
- 🧠 Integrates a trained ML model with real data preprocessing
- 🎯 Real-time predictions with results shown instantly
- 💡 Clean and intuitive result display with conditional formatting
- 🧩 Modular code for easy updates and future expansion
